# Chess-Data-Bank

## HCA rating improvement analysis

The repository now includes the Hatsun Chess Academy January–October 2026 FIDE Standard rating analysis:

- `hca_rating_improvement_dashboard.html` — standalone HTML dashboard.
- `hca_student_rating_change_october_2026.xlsx` — student rating changes, monthly history, games, and estimated tournaments.
- `hca_player_mapping.csv` — FIDE player identity mapping.
- `hca_tournament_calendar.html` — tournament records grouped by month and starting rating range for HCA players.

Estimated tournaments use the requested assumption of nine rated games per tournament. They are estimates, not confirmed event counts.

The dashboard also includes a rating-improvement calendar showing which players gained rating each month, grouped by their prior-month rating band.
